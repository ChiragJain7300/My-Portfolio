# Chirag Jain Portfolio

A modern, interactive personal portfolio showcasing my projects and professional experience.

## Features (Current Branch)
- **Interactive UI:** Includes a custom command palette and live terminal components.
- **Engaging Animations:** Features a custom cursor, loading screen, scroll reveal animations, and interactive hero section particles.
- **Responsive Design:** Refined typography and adaptive layouts across all devices.

## Tech Stack
- **Framework:** Next.js 14
- **Styling & Animations:** Tailwind CSS, Framer Motion, Three.js
- **Monitoring:** Sentry
- **Deployment:** Vercel

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
